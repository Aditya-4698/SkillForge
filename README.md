# SkillForge

SkillForge is a Django-based personal learning and skill management platform.

It helps users organize their learning journey by managing skills, goals, tasks, projects, roadmaps, challenges, notes and learning activities.

## Features

- User Authentication
- Skill Management
- Learning Goals
- Goal Tasks
- Project Management
- Project Milestones
- Learning Roadmaps
- Roadmap Steps
- Challenges
- Notes
- Profile Management
- Progress Tracking
- Activity Tracking
- Dashboard
- Responsive UI

## Tech Stack

- Python
- Django
- HTML
- CSS
- Bootstrap
- JavaScript
- SQLite
- Git & GitHub
